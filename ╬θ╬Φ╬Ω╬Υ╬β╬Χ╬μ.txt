ΖΑΡΙΑ – εγκατάσταση στο Android
================================

Η εφαρμογή είναι PWA: ανεβαίνει σε μια δωρεάν σελίδα και μετά
την εγκαθιστάς από το Chrome. Στο Android το Chrome φτιάχνει
πραγματικό app (εικονίδιο, πλήρης οθόνη, εμφανίζεται στις
εφαρμογές) και δουλεύει και χωρίς ίντερνετ μετά το πρώτο άνοιγμα.
Το κούνημα για ρίψη δουλεύει μόνο έτσι, όχι μέσα στο Claude.

1. Ανέβασμα (GitHub Pages, δωρεάν)
   - Φτιάξε νέο repository στο GitHub, π.χ. "zaria" (Public).
   - Ανέβασε τα αρχεία αυτού του φακέλου (index.html, manifest.webmanifest,
     sw.js, icon-180.png, icon-192.png, icon-512.png) στη ρίζα του repo.
   - Settings → Pages → Source: "Deploy from a branch",
     Branch: main, φάκελος: / (root) → Save.
   - Σε 1-2 λεπτά η σελίδα είναι στο https://<όνομα-χρήστη>.github.io/zaria/

   (Ή με git από το τερματικό:
      git init && git add . && git commit -m "Zaria"
      git branch -M main
      git remote add origin https://github.com/<όνομα-χρήστη>/zaria.git
      git push -u origin main
    και μετά το βήμα Settings → Pages.)

2. Εγκατάσταση στο κινητό
   - Άνοιξε τη διεύθυνση στο Chrome του κινητού.
   - Μενού (⋮) → "Εγκατάσταση εφαρμογής" ή "Προσθήκη στην αρχική οθόνη".
   - Άνοιξε το Ζαριά από το εικονίδιο, κούνα το κινητό, ρίχνει.

Σημειώσεις
   - Το κούνημα θέλει HTTPS (το GitHub Pages το έχει) και ανοιχτή οθόνη.
   - Αν αλλάξεις κάτι στον κώδικα, άλλαξε και το "zaria-v1" σε "zaria-v2"
     στο sw.js, για να πάρει το κινητό τη νέα έκδοση.
   - Δοκιμή στον υπολογιστή: python3 -m http.server μέσα στον φάκελο,
     και άνοιγμα στο http://localhost:8000
